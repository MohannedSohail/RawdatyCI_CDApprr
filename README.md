# ✨ Features

- 👨‍💼 Admin Dashboard
- 👩‍🏫 Teacher Management
- 👨‍👩‍👧 Parent Portal
- 📚 Student Tracking
- 📅 Attendance System
- 🔐 Authentication & Authorization
- 🖥️ Desktop Support
- 📱 Android Ready
- 🌍 Cross-platform Architecture
- 💬 Notifications & Communication

# ⚙️ Installation

```bash
git clone https://github.com/MohannedSohail/RawdatyKMPApp.git
```

Open the project using:

- Android Studio
- IntelliJ IDEA

Run Desktop App:

```bash
./gradlew desktopRun
```
